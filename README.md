A small program that writes one haiku about debugging, in strict 5-7-5 form, to `/output/entry.txt`. Run it with `python3 main.py`. It uses only the Python standard library, needs no network access, and reads no input files.

The haiku it writes:

> green on my machine
> red on the server at dawn
> the clock was the bug

Green locally, red in production, and the culprit turns out to be the clock — the kind of bug that only shows up when the machine changes.
